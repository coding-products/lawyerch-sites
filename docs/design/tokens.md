# 设计系统 · lawyerch

> 建立日期：2026-11-20
> 状态：**生效**。任何新页面、新组件从这里取值，不允许临时决定颜色和字号。

## 0. 一句话原则

**模型负责语义，脚本负责像素。**

写代码时想的是"这块要传达什么"，不是"这块用什么颜色"。颜色从下面的白名单里取，取不到就说明设计有问题，不是白名单有问题。

## 1. 色彩

### 1.1 品牌色板（唯一允许的颜色）

| Token | 值 | 用途 |
|---|---|---|
| `--swp-ink` | `#0f1b2d` | 主色。深色底、正文强调 |
| `--swp-graphite` | `#1c2e4a` | 主色的浅一档，深色区的次级块 |
| `--swp-lime` | `#c9a227` | **唯一的强调色**。金色 |
| `--swp-lime-deep` | `#b08a1e` | 强调色的按压态 |
| `--swp-accent-ink` | `#7d6014` | 强调色在浅底上当文字用（保证对比度） |
| `--swp-slate` | `#47505e` | 次要文字 |
| `--swp-faint` | `#5f5b4d` | 三级文字 |
| `--swp-mist` | `#f5f2ea` | 浅底（米色，不是纯白） |
| `--swp-line` | `#e5e0d3` | 分割线、边框 |
| `--swp-shell` | `#ffffff` | 纯白，只用于卡片内层 |

### 1.2 白名单（`scripts/check-tokens` 校验）

```json
[
  "#0f1b2d", "#1c2e4a", "#c9a227", "#b08a1e", "#7d6014",
  "#47505e", "#5f5b4d", "#f5f2ea", "#e5e0d3", "#ffffff",
  "#000000", "#3fa34d"
]
```

`#000000` 用于纯黑文字兜底，`#3fa34d` 是状态色（在线/成功），只允许出现在状态标记。

### 1.3 硬规则

1. **只有一个强调色**。金色之外不允许出现任何彩色。
2. **新增颜色必须过三道检查**：
   - 格式是 `#RRGGBB`
   - 饱和度 ≥ 0.2（不能是灰，否则和灰阶梯分不开）
   - 当文字压在底色上，对比度 ≥ 4.5:1
3. **白名单外的颜色一律拒绝**，包括 `rgba()` 里写死的色值。
4. **SVG 里也不许硬编码**，用 `currentColor` 或 CSS 变量。

## 2. 字体

| 用途 | 字体栈 | 字号 | 字重 | 字距 |
|---|---|---|---|---|
| 中文大标题 | `Songti SC, Noto Serif SC, serif` | clamp(32px, 4vw, 52px) | 700 | 0.04em |
| 中文段落标题 | 同上 | clamp(22px, 2.6vw, 32px) | 700 | 0.03em |
| 西文标题 | `Space Grotesk` | 同上 | 700 | -0.02em |
| 正文 | `PingFang SC, Noto Sans SC, system-ui` | 16px | 400 | normal |
| 次要文字 | 同上 | 14.5px | 400 | normal |
| 小标签 | `Space Grotesk` | 12px | 600 | 0.18em |

**规则：**

1. **中文标题用宋体，正文用黑体。** 这是中文排版里"专业但有辨识度"的标准组合，系统自带，不增加加载。
2. **标题字距加宽**（0.03–0.06em）。中文标题不加字距会显得挤。
3. **正文行高 1.75**，宋体行高 1.6（宋体自带留白）。
4. **字号下限 12px**，`design-check` 会拦。
5. **西文和数字用 Space Grotesk**，和中文系统字体混排时对比明显。

## 3. 间距

只用 8 的倍数：

```
4  8  12  16  24  32  40  48  64  80  96  120
```

区块间距：

| 场景 | 值 |
|---|---|
| 区块之间 | clamp(48px, 6vw, 88px) |
| 区块内标题到内容 | clamp(20px, 2.6vw, 32px) |
| 段落之间 | 16px |
| 卡片内边距 | clamp(24px, 3vw, 40px) |
| 页面左右边距 | clamp(20px, 5vw, 64px) |

## 4. 圆角

**只有三个值，不许出现第四个：**

| Token | 值 | 用途 |
|---|---|---|
| `--r-sm` | 10px | 小元素、标签 |
| `--r-lg` | 26px | 卡片、图片容器 |
| `--r-pill` | 999px | 按钮、胶囊导航 |

## 5. 对比度底线

| 场景 | 最低对比度 |
|---|---|
| 正文 | 4.5:1 |
| 大字（≥24px 或 ≥18.66px 加粗） | 3:1 |
| 图标、边框 | 3:1 |

`design-check` 会自动校验。手工检查：

```bash
./scripts/check-tokens sites/<domain>
```

## 6. 禁止事项

这些是 AI 生成设计最常见的"味道"，一律不许：

| 禁止 | 原因 |
|---|---|
| 标题里单独给一个词换色/加粗 | 廉价强调，模板脸的第一特征 |
| 全大写做标签 | 中文站用全大写英文标签是硬翻译腔 |
| 内容上方的装饰性小标签 | 不编码信息，只装饰 |
| 彩色渐变 | 和"只有 1 个强调色"冲突 |
| 阴影超过两层 | 廉价感来源 |
| 每张卡片都有 hover 上浮 | 无差别动效等于没有动效 |
| 01 / 02 / 03 编号 | 除非内容真的是序列 |
| 荧光色、高饱和色 | 违反饱和度检查 |
| 模板残留色 | 违反白名单 |

## 7. 校验

```bash
./scripts/check-tokens sites/lawyerch.cn      # 色彩白名单 + 饱和度 + 对比度
./scripts/design-check sites/lawyerch.cn      # 字号 + 触控 + 图片 + 滚动
```

两个都过才能上线。

## 8. 变更流程

改设计系统 = 改这个文件，不是改某个页面。

1. 提出新颜色/新字号
2. 过三道检查
3. 更新白名单
4. 跑 `check-tokens` 全站验证
5. 提交时在 commit message 里说明理由

**不允许**"这个页面特殊，先用一下"。
